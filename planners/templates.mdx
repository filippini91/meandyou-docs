Templates save you from rebuilding the same messages, tasks, and plans for every new client. Your workspace has six kinds of templates, each on its own tab of the Templates page.

## Messages

Save short, reusable message texts (a title and a body). Apply one from the templates button in the [Messages](/planners/messages) composer — it drops the saved text into whatever conversation you're writing, ready to send or tweak.

## Emails

Save a subject and a rich-text body for emails you send often. Create, duplicate, and delete them the same way as message templates.

<Note>
  Email templates aren't currently reused automatically elsewhere in the product — they're a personal library you copy from when writing to a client.
</Note>

## Tasks

Organize task templates into named groups (for example, "12 months out" or "Day-of checklist"), each holding individual task items with an optional description, tags, and how many days before the wedding they're due. You can:

- Apply a **single item** when adding a task to a client (prefills the new task form).
- Apply a **whole group** at once, either from [Tasks](/planners/tasks) or a client's own task list.
- Set a task group as the **default** applied automatically to every new client in [Workspace settings](/planners/workspace-settings#client-defaults).

## Calculator

Save a flat list of calculator line items (title, unit, calculation method, and quantity). Apply one item at a time to a client's calculator from inside their wedding, or set your whole list as the **default calculator** new clients start with.

## Questionnaire

Organize questionnaire templates into groups of questions (free text, single choice, or multiple choice, with their own answer options). Import a whole group — or a single question — into a client's questionnaire editor; you'll still need to save the questionnaire afterward to make the import permanent. You can also set a group as the **default** for new clients.

## Schedule

Organize schedule templates into groups made up of days, each with its own timeline items (name, start and end time, description, and whether it's visible to guests). Import a whole group into a client's empty schedule, or add a single item from a template when building out one day. A schedule group can also be set as a **default** for new clients.

## Editing, duplicating, and deleting

Every template (and every group) has a menu with **Edit**, **Duplicate**, and **Delete**. Duplicating is a fast way to create a variation of an existing template without starting from scratch; deleting always asks you to confirm first.

<Tip>
  The [AI assistant](/planners/ai-assistant) can create, edit, and apply most of these templates for you — just describe what you want in a workspace chat.
</Tip>
