The workspace Tasks page shows every task across every client wedding you manage, so you can plan your week without opening each wedding one at a time.

## The task list

Each task shows which client it belongs to, its due date, its assignee, and any tags. Completed tasks are hidden by default — turn on **Show completed** in the filters to see them.

## Searching, filtering, and sorting

Use the search box to find a task by name. The filter button lets you narrow the list down by client, assignee, tags, and due date range. Sort by due date, name, creation date, client, or assignee, in either direction.

<Tip>
  Sorting by client groups the list under a heading for each wedding, which is useful when you want to review one client's full task list without filtering everything else out.
</Tip>

## Adding a task

Click **New task** to create a single task from scratch, choosing which client it belongs to. Use the arrow next to it to instead add a task (or a whole group of tasks) from your saved [task templates](/planners/templates#tasks):

- Picking a single template item prefills a new task for you to review and save.
- Picking a whole group adds every task in it at once. If you manage more than one client, you'll be asked which client to add the group to.
